## 项目成果优化说明
### 1.优化tag1存在的bug与问题
    bug:退出异常，CTRL+c退出的时候会报sendmsg error: bad address。
    解决方案：在停止进程时break出发送线程回收资源，在udp线程里添加一个判断running的功能，及时跳出发送
    删除调试信息。
### 2.同端口的tcp接发出现的问题
    bug:在程序初始化后没有调用tcpsend的时候，tcprecv一直不能正确接收识别上位机指令。在recv里加了很多printf来输出调试信息
    并没有效果。但用了send之后接收成功。后续定位到接收端线程一直被阻塞，没有到正确的逻辑里去，判断是connected变量在初始化的时候没有正确的改变值，导致
    后续一直阻塞。
    解决方案:在tcpinit的时候如果成功连接直接修改connected的值。
